How to use

Create

  • Enter a prompt describing the image you want.
  • Pick aspect ratio and model (prices shown in picker).
  • Tap Generate. Result appears below.
  • Use "Use as edit input" or "Iterate" to continue.

Combine

  • Add 1-3 images (max 25MB each, HEIC supported).
  • Write a prompt describing the blend.
  • Select a combine-capable model.
  • Tap Blend to generate the merged result.

Edit

  • Upload a single photo (drag, paste or tap).
  • Optional: tap "Paint mask" and brush over the part to change. Only that area is replaced.
  • Write your edit prompt and choose an edit model.
  • Tap Apply Edit. Press and hold the result to compare with the original.

Models + pricing

All models come from the live Venice catalog. Create lists text-to-image models; Edit and Combine list only Venice's image-edit models. Prices are shown in the model picker.

Privacy

Models run with the privacy level shown per model in the picker (anonymized or private). History stays on this device.

Mercury optimizer

Optional. Tap the star button next to any prompt to rewrite it. Preview the optimized version before applying. Never automatic.
