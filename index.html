How to use

Create

  • Enter a prompt describing the image you want.
  • Pick aspect ratio and model (prices shown in picker).
  • Tap Generate. Result appears below.
  • Use "Use as edit input" or "Iterate" to continue.

Combine

  • Add 1-3 images (max 25MB each, HEIC supported).
  • Write a prompt describing the blend.
  • Select a combine-capable model.
  • Tap Blend to generate the merged result.

Edit

  • Upload a single photo (drag, paste or tap).
  • Optional: tap "Paint Mask" to selectively edit areas.
  • Write your edit prompt and choose model + aspect.
  • Tap Apply Edit. Result shows with compare slider.

Models + pricing

All models come from the live Venice catalog. Prices are shown in the model picker. Grok Imagine 2.0 is the default for Create; Grok Imagine 2.0 Edit is default for Edit and Combine.

Privacy

Models run with the privacy level shown per model in the picker (anonymized or logged).

Mercury optimizer

Optional. Tap the star button next to any prompt to rewrite it. Preview the optimized version before applying. Never automatic.
